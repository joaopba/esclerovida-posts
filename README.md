# EscleroVida – artes do Instagram

Artes publicadas no Instagram [@esclero_vida](https://www.instagram.com/esclero_vida/) via Metricool.

- `REGRAS.md` — regras de conteúdo (o que pode e o que nunca pode aparecer)
- `PAUTAS.md` — temas aprovados e os fatos que cada um pode usar
- `HISTORICO.md` — o que já foi publicado
- `gerador/render.py` — gera as artes no visual padrão a partir de um JSON
- `feed/` — posts de feed (1080×1350), com o JSON e a legenda de cada um
- `stories/` — stories (1080×1920)

As imagens daqui são públicas porque o Metricool precisa de um link aberto para publicar.
As fontes Inter seguem a licença em `gerador/fontes/LICENCA-INTER.txt`.
